Text

data-element="text" · required · maxlength

data-element="email" — checks the format

data-element="url"

data-autocomplete="true" · data-source="api/…" asks GET ?q=… and reads [{value, text}]

data-element="textarea" · data-auto-resize · data-char-count · maxlength

Numbers and formats

data-element="number" · data-precision="2" · data-use-grouping · data-allow-negative · min / max

data-element="currency" · data-decimals · selects its text on focus

data-element="tel" — the ready-made mask 99-9999-9999

data-element="mask" data-format="idcard" (also: date, time, datetime, creditcard, ip, zipcode)

data-element="mask" data-pattern="aa-9999" — 9 = digit · a = letter · * = either

Date and time

type="date" data-element="date"

type="datetime-local" data-element="date"

type="time" data-element="date"

data-element="daterange" · data-range-end names the end field · data-range-presets

Choices

data-element="select" · data-placeholder · options from <option> or data-options-key (API)

data-element="select-multiple" on a <select multiple>

data-element="tags" · data-max-tags · Enter or comma adds · Backspace removes the last

data-source="api/…" with data-allow-new="false" — only values the server offered can become tags

.form-control.radiogroups around native radios

input.switch — a checkbox drawn as a toggle (not sent when off)

a native checkbox with required

Colour and range

type="color" data-element="color" — palette plus a hex box

type="range" data-element="range" · data-show-labels · data-prefix / data-suffix

data-range turns it into min–max, value="2000,8000" is posted as that text

Password and files

data-element="password" · data-password-strength

data-target-password="#el_password" — compared with the other field

data-element="file" · data-preview · data-drag-drop · data-max-file-size (bytes) — the demo server does not store them

data-crop · data-crop-aspect="1" · data-crop-shape="circle" · data-crop-width="400" — drag, zoom and turn the image in the frame; the server gets the cropped image

data-crop-aspect="3/4" · data-crop-format="webp" · data-crop-min-width="300" · multiple — each image is cropped in turn; the crop button on a preview crops it again from the original

Code

data-element="code" · data-language (javascript, json, html, css, php, sql, text) · data-min-lines · data-max-height · data-theme
