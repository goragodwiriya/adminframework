Tabs

data-component="tabs" · data-default-tab · data-hash="false" (the default keeps the active tab in the URL hash so Back works)

Content of the first tab. Arrow keys, Home and End move between tabs.

The second tab is open first because of data-default-tab="two".

Panels are plain HTML — put a form, a table or another component in them.

Image gallery

data-component="image-gallery" · data-effect="fade|slide|none" · data-aspect · data-thumbnails-position · data-enable-zoom · or data-api="…" to load the list from a URL

Calendar

The calendar of the home page (EventCalendar) lists the events of every module. A module adds its own through the initCalendarSources and initCalendarEvents hooks, as modules/demo does
