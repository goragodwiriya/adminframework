{LNG_Example} {LNG_Rich Text Editor}

{LNG_One textarea becomes a full editor. Pick a profile, set the height, read and write the content from JavaScript}

Profiles

A profile is a ready-made toolbar and plugin set chosen with data-rte-profile

data-element="richtext" data-rte-profile="basic" (the default when none is given is full)

data-rte-profile="full" · data-rte-sticky="true" keeps the toolbar at the top of the screen while you scroll a long document

data-rte-profile="minimal" · data-rte-height="180" fixes the height (px) · also data-rte-min-height and data-rte-max-height

data-rte-profile="comment" · data-rte-placeholder (or the native placeholder) — short replies, limited to 2000 characters with a counter

data-rte-profile="email" · data-rte-fonts="Sarabun|Kanit|Tahoma, sans-serif" limits the font dropdown (separated by |, or a JSON array) — plus lists, alignment, links, images and a 10-second draft autosave

The factory puts setValue, getValue, focus, clear and setReadOnly on the field's instance (ElementManager.getInstanceByElement)

the native readonly attribute (or data-read-only="true") starts an editor read only

Good to know
  • The editor returns the HTML exactly as written. The server decides what to keep: ->detail() keeps everything, ->detail(false) removes what can run JavaScript, ->cleanHtml() keeps formatting only
  • Images and links can be picked from the file browser (js/components/editor/php/filebrowser.php, folder datas/images)
  • The AI buttons of the basic and full profiles call api/index/aiwriter, which this base project does not include
